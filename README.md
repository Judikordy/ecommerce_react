# 🛒 E‑Commerce Web Application (React)

A modern **responsive e‑commerce web application** built using
**React.js** that simulates an online shopping experience with product
browsing, cart management, and dynamic UI interactions.

------------------------------------------------------------------------

## 🚀 Live Features

-   🧾 Product listing with dynamic rendering\
-   🔍 Product details view\
-   🛒 Shopping cart management\
-   ➕ Add / Remove items from cart\
-   💰 Price calculation and cart updates\
-   📱 Fully responsive design\
-   🔄 API integration for fetching product data\
-   ⚡ Fast single‑page application using React

------------------------------------------------------------------------

## 🧰 Tech Stack

-   **Frontend:** React.js, JavaScript (ES6+)
-   **Styling:** CSS3 / Responsive Layout
-   **State Management:** React Hooks (`useState`, `useEffect`)
-   **API Handling:** REST APIs / Fetch or Axios
-   **Version Control:** Git & GitHub

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

git clone https://github.com/Judikordy/ecommerce_react.git

### 2️⃣ Navigate to project folder

cd ecommerce_react

### 3️⃣ Install dependencies

npm install

### 4️⃣ Run the application

npm start

The app will run locally at:

http://localhost:3000
